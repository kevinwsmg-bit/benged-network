BENGED NETWORK SETUP

Your WARDOGS overlay watches the game the same way viewers do and reacts on its own: heli crashes, getting knocked down, revives, the vendor, the pilot seat and more. It only reads the picture OBS already has. It never touches the game, so anti-cheat has nothing to see.

The short version

1Double-click SETUP.bat (once).
2Turn on OBS WebSocket and add one browser source (once).
3Every stream: double-click START.bat and leave its window open. Updates install themselves.

1 · Install (one time, about 5 minutes)

  1. Unzip the folder somewhere it can stay, for example Documents\benged-network.
  2. Double-click SETUP.bat. It needs Python 3.12 and installs it for you if it's missing. Newer versions like 3.13 or 3.14 are too new for the text reader, but they can stay installed alongside it.
  3. It then downloads the reader (about 150 MB) and says Done when it finishes.

2 · OBS (one time)

Turn on the WebSocket

  1. OBS → Tools → WebSocket Server Settings.
  2. Tick Enable WebSocket server (port 4455), then Show Connect Info and copy the password.

Add the overlay

  1. In your WARDOGS scene: + → Browser, name it Benged Network.
  2. URL:
    http://localhost:8765/overlay
  3. Width 1920, Height 1080. Tick Control audio via OBS so the overlay's sounds get their own volume slider.
  4. Drag it above the game capture. Your webcam goes under it (next step).

Move your webcam

The overlay draws a frame for your cam at the top-left: X 24, Y 22, size 360 × 203 (on a 1920 × 1080 canvas). Put your webcam source there, under the overlay. This also stops your cam covering the game's kill feed.

Optional: auto-save clips

OBS → Settings → Output → Replay Buffer → enable it, and press Start Replay Buffer when you go live. Then tick the replay-buffer box in the control panel. About 8 seconds after a heli crash, a 100 m+ kill, or 3 kills in a minute, OBS saves the replay buffer (the last 20–30 seconds, whatever length you set in OBS) to your recordings folder.

3 · Every stream

  1. Open OBS and WARDOGS.
  2. Double-click START.bat. Leave the black window open. The control panel opens in your browser.
  3. First time only, Step 1: paste the OBS WebSocket password and press Connect. The top-right light turns green and the source list fills in. If it doesn't, the red message under the password says why.
  4. First time only, Step 2: pick the source that shows WARDOGS (your Game Capture, not the scene), check your in-game name says Benged (add others with commas if you play on another account), and press Save.
  5. Check What the reader sees shows your game with yellow boxes around the cash, kill feed and heli controls.
  6. Press a few Test buttons. You should see and hear them on the overlay.
  7. Press Reset overlay for a new stream before you go live, so test clicks don't count. Restarting START.bat also starts fresh.

Channels switch the moment the reader is sure what you're doing, and the newest activity wins. Each one drops back to Combat 30 s after that activity stops.

Game settings: keep WARDOGS at 16:9 with the default HUD scale. If the yellow boxes miss the HUD, screenshot the control panel and send it to Kevin.

Updates

Kevin keeps improving the overlay. You never need a new zip again:

  • START.bat checks for a new version each time you start it and installs it before the overlay opens.
  • If an update comes out while it's running, your control panel shows Update available. Press Update now (best between streams; the overlay restarts fresh).
  • If an update ever fails to start, it puts the previous version back on its own.

If something looks wrong

  • Wrong celebration? Press Pause reader in the control panel. The overlay stays up but stops reacting.
  • Missed something? Note the time it happened. The control panel's Live events list shows everything the reader saw.
  • Send Kevin: a screenshot of the control panel and the time of anything odd. That's enough to fix it.
  • Overlay shows "OVERLAY OFFLINE": START.bat isn't running.
  • Top-right says "overlay NOT connected": the OBS Browser source isn't loading the overlay. Check its URL is exactly http://localhost:8765/overlay, Local file is unticked, size 1920 × 1080, then press Refresh cache of current page.
  • Flying but no Benged Air? Look at Heli gauges in the control panel while you fly. Send Kevin a screenshot if it stays at "—".
  • Too heavy on your PC? It reads 3 times a second and uses about one CPU core at most. Lower "fps" to 2 in config.json if you need to.
